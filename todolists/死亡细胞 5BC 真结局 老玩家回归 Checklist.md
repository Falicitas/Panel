# 死亡细胞 5BC 真结局 老玩家回归 Checklist

从 1.x 时代回归，只有本体，目标是冲到 5BC 通关并解锁观星台双打收藏家拿真结局。

前提假设：你对手感、翻滚无敌帧、连击、跑酷这些底层逻辑还有肌肉记忆，主要补的是 1.x 之后的系统重做：三色卷轴 + 突变重做、诅咒箱、传奇锻造所、武器品质后缀、5BC 真结局流程。

***

## Phase 0 — 状态盘点 (\~15min)

先搞清楚自己现在站在哪。

* [x] 启动游戏，进牢房看难度选择有几个细胞 — 1.x 时代你大概有 0\~2 BC 解锁，记下当前是几细胞起步

* [x] 在牢房左下角找收藏家投资界面 — 这个界面替代了 1.x 的"图纸研究"机制，所有图纸现在都在这里花细胞解锁

* [x] 不要急着开新局，先看一遍图纸库存 — 滚轮翻一遍，被忽略的紫色/绿色武器很多是后期重做过的

* [x] 看一眼"习惯"投资项 — 血瓶次数、商人换货、铁匠重铸、装备回收，这些功能性投资优先级最高
  * 🔍 1.x 时代很多功能是默认开的或不存在的，现在全部要细胞投资。优先点：血瓶 ×2、商人换货 1 级、铁匠 1 级、装备回收 1 级

* [x] 跑一局 0BC 不死任何东西，只为感受当前手感 — 注意黄血回血机制（受伤后 80% 转为黄条，攻击可以恢复）

***

## Phase 1 — 三色卷轴 + 黄血机制 (\~30min)

1.x 时代是直接 +HP 或 +伤害卷轴，现在重做成红/紫/绿三色 + 双色卷轴。这是版本最大变化，先吃透。

* [x] 再跑一局，只拿紫卷轴，配重弩或迅捷之弓 + 两个炮台 — 体验紫流的猥琐打法
  * [ ] 看看紫流的搭配攻略

* [ ] 第三局，只拿绿卷轴，配盾 + 慢速重武器（巨剑、镰刀类）— 体验绿流换血流

* [x] 受伤后故意贪一刀，看黄血怎么回 — 每 hit 恢复当前伤害的 12%，最高回 20% 总血
  * 🔍 这个机制鼓励贪刀，慢速重武器单次伤害高，更容易把黄血吃回来。这就是绿流敢挨打的原因

***

## Phase 2 — 突变三槽 + 装备颜色匹配 (\~20min)

1.x 时代突变是直接 buff，现在每关结束在收藏家旁边的 Guillain 那选，最多三个槽，可以花金币重置。

* [x] 在锻造所体验花金币重置突变 — 进 boss 关之前可以针对 boss 重新配

***

## Phase 3 — 诅咒箱 + 挑战区域 + 卷轴数量平衡 (\~20min)

这两个机制 1.x 时代不存在或形态完全不同，是 5BC 的核心收益来源。

* [ ] 找一次挑战区域 — 地板上有符文标记，触发后进入限时陷阱关，奖励是必给三色卷轴 + 饰品 + 细胞
  * 🔍 跑酷不要光看怪，地板符文一眼扫过容易错过。每张地图 20% 概率刷

* [ ] 找一次时限门 — 限时内到达可拿细胞 + 卷轴 + 金币，首次到达还有图纸

***

## Phase 4 — 路线规划：本体 5BC 真结局完整流程 (\~30min)

本体（无 DLC）冲 5BC 真结局的路线相对固定。重点是找到你能稳过的版本。

* [ ] 写下 5BC 卷轴最多路线（仅本体可达部分）— 牢房 → 猛毒下水道 → 腐化牢房 → 旧下水道 → 作呕地窖 → 沉睡的庇护所 → 山巅城堡 → 王座之间 → 观星实验所 → 观星台
  * 🔍 山洞 → 守护者居所是 DLC 巨人崛起的内容，本体没有。你的 5BC 解锁靠王手，不是巨人

* [ ] 跑一局 0BC 走推荐稳健路线 — 牢房 → 有罪者的大道 → 壁垒 → 作呕地窖 → 山巅城堡 → 王座之间

* [x] 再跑一局 0BC 走诅咒箱路线 — 牢房 → 猛毒下水道 → 腐化牢房（这里后4张卷轴） → 旧下水道 → 作呕地窖 → 墓地 → 被遗忘的陵墓 → 时钟楼 → 山巅城堡 → 王座之间（玩紫流弹药要够）
  * 🔍 后者卷轴最多但要开诅咒箱，前者更稳

* [ ] 跑酷党路线试一次 — 监狱深处比壁垒难但有更多时限门，4 个时限门全开可以滚出大量卷轴

* [ ] 在收藏家界面解锁建筑师钥匙、传送符文、牧羊符文、人造人符文、蜘蛛符文（分别在固定地图打精英怪）
  * 🔍 符文是永久解锁，开新局也保留。优先解锁顺序：藤蔓符文 → 传送符文 → 蜘蛛符文 → 牧羊 → 人造人

***

## Phase 5 — BC 难度阶梯：1BC → 4BC (\~多局，按段位推进)

BC 数变化：怪更强、卷轴更多、休息区回血变少、诅咒箱奖励质变。

* [ ] 通关 0BC 拿第一颗起源细胞 — 王手掉

* [ ] 1BC 通关 — 怪开始有质变（出现新精英类型），卷轴数量增加

* [ ] 2BC 通关 — 休息区回血明显减少，开始考验你的过图无伤能力

* [ ] 3BC 通关 — 诅咒箱开始变得划算，铁匠重铸开始大量使用

* [ ] 4BC 通关 — 这一关后王手会触发特殊对话，解锁第 5 颗起源细胞和观星实验所
  * 🔍 4BC 通关 ≠ 解锁 5BC 真结局。4BC 第一次打过王手才是触发点。要看到对话出现

* [ ] 在每个 BC 阶段都至少打一次诅咒箱，逼自己习惯压力 — 5BC 没诅咒箱玩不动

***

## Phase 6 — 装备品质 + 铁匠重铸 + 锻造所 (\~20min)

1.x 时代武器是固定属性，现在有 +、++、S、L 四档品质 + 词条系统。

* [ ] 在锻造所看一次武器属性面板 — 等级（罗马数字）+ 品质（+/++/S/L）+ 词条
  * 🔍 等级是量变，品质是质变。S 品质 = ++ + 1 级

* [ ] 在收藏家投资铁匠 1 级 — 解锁后每关锻造所可以重铸武器一次

* [ ] 投资铁匠 2 级 — 解锁锻造所升级品质功能（boss 战后细胞投资）

* [ ] 重铸一次刷词条 — 看哪些词条是好的：纯"X% 伤害"无条件加成是顶级（一般带星）

* [ ] 跑一局体验全程升品质打法 — 每个锻造所都升一档品质，到 5BC 王手前争取拿到 S/L 武器

***

## Phase 7 — 5BC 真结局完整跑通 (\~按局数推进)

到这里你应该已经能稳过 4BC。下面是真结局触发流程。

* [ ] 4BC 跑一局，确认击败王手后看到细胞人和王手的对话场景 — 没看到说明本局没触发
  * 🔍 触发条件：4BC 难度 + 第一次击败王手。如果你之前 4BC 已经通关过没触发对话，正常下一次 4BC 通关也会触发

* [ ] 解锁 5BC 后跑一局 5BC 标准通关 — 走最远路线尽量多拿卷轴和属性点

* [ ] 5BC 王手通关后不要直接退游戏，进入观星实验所 — 这是新增的最终关

* [ ] 在观星实验所末尾打第一次收藏家 boss — 比王手难，保留至少 2 个血瓶

* [ ] 第一次收藏家通关后，进入下一局 5BC — 这次的目标是夺取国王身体

* [ ] 5BC 再次打王手，触发夺身剧情 — 注意是要在王手身上抢身体，不是常规通关

* [ ] 带着国王身体进观星实验所 → 观星台，第二次打收藏家 — 真结局触发

***

## Phase 8 — 5BC 持续优化 (\~长期)

通关只是开始，5BC 速通和无伤是另一个阶段。

* [ ] 5BC 通关 5 次，每次刻意用不同流派 — 红/紫/绿都吃透

* [ ] 5BC 体验一次自定义模式 — 锁武器池刷你想要的金武

* [ ] 解锁所有本体武器图纸 — 收藏家界面应该全亮

* [ ] 解锁所有本体突变图纸 — 同上

* [ ] 试一次 5BC 无伤过 boss 拿金武 — 王手无伤是基本功

* [ ] 💡 解锁所有本体符文 — 藤蔓、传送、蜘蛛、牧羊、人造人，最后一个最难

* [ ] 💡 跑一次每日挑战 — 给传奇威力卷轴（三属性 +1）

***

## 品味校准 (\~5min)

通关 5BC 真结局之后再回头填这部分，逼自己形成观点。

* [ ] 生死判断 — 死亡细胞这种纯本体内容（无 DLC）的设计，5BC 强制硬核才能看真结局，这个设计你认同吗？还是觉得是把核心剧情门槛设得过高了？

* [ ] 需求真伪 — 三色卷轴 + 突变三槽这套系统，相比 1.x 的简单 +HP/+伤害，是真的提升了 build 深度，还是给 roguelite 强行套了个 RPG 皮？

* [ ] 核心设计决策 — 黄血贪刀机制是死亡细胞跟 Hades、Hollow Knight 走的不同路。这个 tradeoff 你认同吗？它鼓励了什么打法、惩罚了什么打法？

* [ ] DX 打分（1-5）— 上手摩擦、信息呈现（卷轴选择界面）、报错（诅咒解释清不清楚）、生态（mod、自定义模式）

* [ ] 一句话总结 — 老玩家回归 → 通关 5BC 这趟体验，你会推荐还是劝退还在 1.x 印象里的同期玩家？

* [ ] 老玩家专属 — 1.x 到现在你最怀念的旧机制是什么？最讨厌的新机制是什么？

* 紫 = 战术 = 远程/炮台

* 10%：有罪者大道、猛毒下水道、旧下水道、雾萦港湾、钟楼

* 110%：藏骨堂、墓地、被遗忘的陵墓、崩坏神庙、庇护所
