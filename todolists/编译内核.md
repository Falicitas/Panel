## Ubuntu 改内核完整流程

### 0. 前置检查
```bash
uname -r                  # 当前内核版本
systemd-detect-virt       # 必须是 kvm/xen/vmware 等，不能是 lxc/docker
nproc && free -h && df -h /   # 建议 4 核 / 8G 内存 / 30G 磁盘
```

### 1. 装依赖
```bash
sudo apt update
sudo apt install -y build-essential git bc bison flex libssl-dev \
    libelf-dev libncurses-dev fakeroot dwarves cpio kmod \
    rsync zstd llvm dpkg-dev

# 启用 source 仓库（Ubuntu 24.04 默认关闭）
sudo sed -i 's/^Types: deb$/Types: deb deb-src/' /etc/apt/sources.list.d/ubuntu.sources
sudo apt update
```

### 2. 拿源码 + 建基线
```bash
mkdir -p ~/kernel-work && cd ~/kernel-work
apt source linux-image-unsigned-$(uname -r)
cd linux-*/

# 建 git 基线（apt source 拿的不是 git 仓库）
git init && git add -A && git commit -m "baseline"
git checkout -b phase15a-rename   # 在新分支上改
```

### 3. 配置内核
```bash
# 复制当前系统的配置当起点
cp /boot/config-$(uname -r) .config
make olddefconfig        # 处理新增配置项，默认值

# 关掉签名相关（自编内核没证书会编译失败）
scripts/config --disable SYSTEM_TRUST_KEYRING
scripts/config --disable SYSTEM_REVOCATION_KEYS
scripts/config --set-str SYSTEM_TRUSTED_KEYS ""
scripts/config --set-str SYSTEM_REVOCATION_KEYS ""
```

### 4. 改源码
改你想改的东西（cpufeatures 字符串之类），完事看一眼：
```bash
git diff
```

### 5. 编译 + 打包
```bash
make -j$(nproc) bindeb-pkg LOCALVERSION=-mykernel
# 大概 20-60 分钟，取决于机器
```

### 6. 安装 + 重启

```bash
cd ..
sudo dpkg -i linux-image-*-mykernel_*.deb linux-headers-*-mykernel_*.deb # 核心。把 .deb 包里的内核文件解压到系统对应位置（/boot/vmlinuz-*、/lib/modules/*/），并自动跑 update-initramfs 和 update-grub，让新内核能被 GRUB 启动菜单识别。
# 通电 → 固件 (UEFI/OVMF) → 引导加载器 (GRUB) → 内核 (Linux) + initrd → 系统
sudo reboot
```

### 7. 验证
```bash
uname -r          # 应该带 -mykernel 后缀
lscpu             # 看你的改动是否生效
```

---

## 救命操作

如果新内核起不来或出问题：
- 重启时在 GRUB 菜单选 **Advanced options** → 选原来的 `6.8.0-111-generic`
- 进系统后卸载坏内核：`sudo apt remove linux-image-*-mykernel`
- 云机器如果 GRUB 菜单看不到，通常控制台有 VNC，或者用快照回滚

---

## 几个要点

- `LOCALVERSION=-mykernel` 必加，能和原内核共存，留后路
- 第一次编译用 `make -j$(nproc)`，之后改一两个文件再 `make -j$(nproc) bindeb-pkg` 只会增量编译，快很多
- `git diff baseline-commit` 随时能看你改了啥
- `.deb` 包可以拷到其他同版本 Ubuntu 机器上直接装
