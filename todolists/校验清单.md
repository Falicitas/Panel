| 寄存器    | 测了什么                                                     | 怎么算 digest                               | 工具                            |
| --------- | ------------------------------------------------------------ | ------------------------------------------- | ------------------------------- |
| **MRTD**  | TDVF 的 BFV（不在 event log 里）                             | 对 `.fd` 跑 page-add+extend 算法            | `mrtd_from_ovmf.go`             |
| **RTMR0** | TD HOB、CFV、SecureBoot/PK/KEK/db/dbx、FV blob               | SB 变量+FV 能逐条算；**HOB 那条只能 pin**   | tpm2 工具 / pin                 |
| **RTMR1** | shim、grub、kernel 三个 PE（你 log 事件 13 那种 `EV_EFI_BOOT_SERVICES_APPLICATION`） | PE **Authenticode** hash（不是文件 sha384） | `pesign -h`                     |
| **RTMR2** | cmdline 含 roothash（事件 19）+ initrd（事件 20）            | 内容 **plain SHA384**                       | `sha384sum` + 算 cmdline 小脚本 |

能全独立复现的只有 RTMR1、RTMR2。RTMR0 大部分能算、HOB 那条 pin。MRTD 要那份 `.fd`——shim/grub 在 ESP 上随便拷，但 **TDVF 在 guest 里读不到**，拿不到就退回"信阿里云 firmware 版本"。
