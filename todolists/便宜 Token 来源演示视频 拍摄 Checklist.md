# 便宜 Token 来源演示视频 拍摄 Checklist

演示"怎么找便宜的 LLM API → 选一个 → 注册拿 Key → 跑通请求"。

前提假设：用 OpenScreen 录屏，演示平台选 2-3 个（DeepSeek / SiliconFlow / OpenRouter 之类），最终选一个跑通。

---

## Phase 0 — 录屏环境准备 (~15min)

把录制工具和演示环境都调好，拍的时候不用停下来折腾。

- [x] OpenScreen 安装好，试录 30 秒确认屏幕+麦克风都能采集到
  - 🔍 确认录制分辨率，zeni 要横屏还是竖屏？竖屏的话提前调好窗口布局
  
- [x] 浏览器准备一个干净的 Chrome Profile — 不要让你的收藏栏、历史记录、奇怪的 tab 出镜

- [x] 把要演示的 2-3 个平台账号提前注册好并登录
  - DeepSeek platform (platform.deepseek.com)
  
  - SiliconFlow (cloud.siliconflow.cn)
  
  - OpenRouter (openrouter.ai)
  
      
  
- [x] 准备一个终端窗口，字体调大到录屏能看清（至少 16px），装好 curl 或者随便一个能发 HTTP 请求的工具

- [ ] 敏感信息检查 — 把终端的环境变量里有 API Key 的都临时 unset 掉，浏览器里其他平台的余额/邮箱等 tab 关掉

---

## Phase 1 — 内容素材准备 (~20min)

拍之前把要展示的东西都准备好，拍的时候直接切过去。

- [ ] 打开各平台定价页，浏览器里按 tab 排好顺序，拍的时候直接 Ctrl+Tab 切换
  - DeepSeek: platform.deepseek.com/api-docs/pricing
  - SiliconFlow: docs.siliconflow.cn/docs/pricing
  - OpenRouter: openrouter.ai/models（可以按价格排序）
- [ ] 做一张简单的价格对比表 — 不用太精致，3-4 个模型横向对比输入/输出价格就行
  - 🤖 这步可以让 Claude 帮你快速生成，给个截图或者 markdown 表格
- [ ] 写一个 curl 请求模板，提前存好，拍的时候 paste 进去就能跑
  - 格式用 OpenAI-compatible 的 `/v1/chat/completions`，这样观众看着熟悉
  - prompt 用个简单的，比如"用一句话解释什么是 API"
- [ ] 想好口播的大纲（不用写逐字稿，列 5-6 个要说的点就够）：
  - 开场：这个视频要解决什么问题
  - 各平台快速过一遍定价
  - 选一个最便宜的（或者性价比最高的）
  - 演示注册 → 拿 Key
  - 发请求 → 看到返回
  - 收尾：一句话总结

---

## Phase 2 — 录制 (~30min)

分段录，别想着一条过。

- [ ] 录制开场段 — 打开浏览器，说清楚"我们今天对比几个平台的 token 价格"
- [ ] 录制对比段 — 逐个切换平台定价页，口述各家价格差异，中间插入你准备的对比表
  - 🔍 观众不需要你念每个数字，挑 1-2 个差异大的点说就行
- [ ] 录制注册段 — 选定一个平台，从官网首页开始，走完 注册 → 登录 → 找到 API Key 页面 → 创建 Key 的全流程
  - 如果平台需要充值才能用，这步也录进去
  - Key 创建后马上复制，别让它在屏幕上停留太久
- [ ] 录制验证段 — 切到终端，paste 你准备好的 curl 命令，把 Key 填进去，发请求，展示返回结果
- [ ] 录制收尾段 — 回到浏览器，一句话总结
- [ ] 每段录完回放检查一次 — 重点看有没有 Key/余额/邮箱等敏感信息露出

---

## Phase 3 — 后期和交付 (~15min)

- [ ] 在 OpenScreen 内置编辑器里拼接分段素材 — 裁剪、缩放、速度调整都在里面搞定
- [ ] 检查全片有没有需要打码的地方 — API Key、邮箱、账户余额、其他 tab 的内容
  - OpenScreen 支持裁剪遮挡，或者用标注功能盖住敏感区域
- [ ] 从 OpenScreen 导出 mp4，导入剪映生成自动字幕
  - 技术术语（API Key、token、endpoint）字幕大概率会错，手动改
- [ ] 导出，发给 zeni 确认

---

## 品味校准 (~5min)

- [ ] 这个视频的目标受众到底是谁？纯小白（连 API 是啥都不知道）还是有点基础的开发者？两者需要的讲解深度完全不同
- [ ] zeni 说的"下载安装"具体指什么？如果目标受众是非技术用户，"注册拿 Key + curl"这套可能还是太硬核了，需要确认
- [ ] 这个视频是一次性交差的，还是后续要做成系列？如果是系列，第一期控制范围别太大
- [ ] 录完自己看一遍，假装你是个没用过 API 的人 — 能跟上吗？
