# 晨起握力模块 PRD Checklist

一句话说明：在个人面板里加一个握力记录模块，每天录入优势手两次数值，自动算基线和偏离，给出今日训练建议。

---

## Phase 0 — 数据模型 (~10min)

- [ ] 定义单条记录结构 — `{ date: 'YYYY-MM-DD', reading1: number, reading2: number }`
  - 🔍 只存两次原始读数，max/avg 算出来就行，不落库
- [ ] 定义存储结构 — 按日期为 key 的对象或数组，任选
- [ ] 定义单位 — kg，保留 1 位小数

---

## Phase 1 — 录入界面 (~15min)

- [ ] 主面板上的录入入口 — 两个数字输入框 + 提交按钮
- [ ] 输入校验 — 0~100 kg 范围，非数字拒绝
- [ ] 当日重复录入处理 — 后录覆盖前录，给个轻提示
- [ ] 录完后立刻显示今日结果 — 最高值、偏离百分比、训练建议

---

## Phase 2 — 基线计算 (~15min)

- [ ] 取最近 14 天数据算均值 M 和标准差 SD
  - 🔍 用每日的 max(reading1, reading2) 作为当日代表值
- [ ] 数据不足 14 天时的处理 — 显示"基线建立中 X/14"，不给训练建议
- [ ] 基线滚动更新 — 每次新增数据自动重算，不缓存

---

## Phase 3 — 训练建议输出 (~10min)

- [ ] 计算今日偏离 — `(today_max - M) / M * 100%`
- [ ] 按 SD 分档输出建议：
  - 偏离在 ±1 SD 内 → "正常，照常训"
  - −1 到 −2 SD → "降强度"
  - < −2 SD → "改有氧或休息"
  - > +1 SD → "状态好，可冲"
- [ ] 文案显示今日偏离值、基线 M、当前 SD，透明可验证

---

## Phase 4 — 历史视图 (~15min)

- [ ] 折线图 — 最近 30 天最高值，叠加 M 和 ±1SD/±2SD 参考线
- [ ] 简单统计 — 近 7 天均值、近 30 天均值、整体趋势箭头
- [ ] 原始数据表格 — 可翻看，支持删除异常数据点
  - 🔍 异常数据点（比如测试姿势错了）会污染基线，要能手动剔除

---

## Phase 5 — 和服药模块的共享外壳 (~10min)

- [ ] 抽出"每日 check-in"的公共容器 — 今天是否已完成录入
- [ ] 未完成时的提醒样式 — 面板顶部红点或 badge
- [ ] 握力和服药作为独立子模块，不互相耦合
  - 🔍 两者数据模型差别大，别硬合并

---

## Phase 6 — 数据导出 (~5min)

- [ ] 导出全部历史为 JSON 或 CSV
- [ ] 💡 导入功能可选，后面需要再加

---

## 品味校准 (~5min)

- [ ] 生死判断 — 这个模块你会坚持用超过 3 个月吗？不会的话砍掉哪些 Phase？
- [ ] 需求真伪 — 握力真的能帮你判断训练与否？还是你其实只是想有个量化仪式？
- [ ] 核心设计决策 — 用 SD 而不是固定百分比阈值，这个复杂度值得吗？
- [ ] DX 打分（1-5）— 每天录入的摩擦有多大？两个输入框会不会让你放弃？
- [ ] 一句话总结 — 这个模块对你的价值是"训练决策工具"还是"数据收藏"？
