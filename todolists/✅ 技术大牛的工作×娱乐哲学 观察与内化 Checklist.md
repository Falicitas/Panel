# 技术大牛的工作×娱乐哲学 观察与内化 Checklist

三个真实案例，提炼工作和娱乐怎么摆的问题，然后自己试一周。

---

## Phase 0 — 读三份一手材料 (~40min)

直接看当事人怎么说。

- [x] 🌟🌟🌟 读 Paul Graham 的 Maker's Schedule, Manager's Schedule — paulgraham.com/makersschedule.html，全文很短 
  - 🌵 点评：作为绝大多数时间为 Maker 的我，本身也很讨厌开会。但开会（探索性的会，大部份的会包括硅谷的商务人士也是）在一个管理本身已经很节制的制度下是免不了的。如果有 4 人会议，我将尝试安排在周日下午（放在一个工作周的结尾）。这样虽然多少影响周日的上午（毕竟被管理者时间表拦腰打断），这样至少对于我可以尽可能地创造最多的创造者时间表。当然，如果可以的话，线上在周日晚上电话会议是最好的。
- [x] 🌟🌟🌟(🌟) 看 Lex Fridman 采访 Carmack — YouTube 搜 "Lex Fridman Podcast #309 John Carmack"，跳到讲 daily routine 的部分（43:00–57:00）
  - 验证什么：字幕源的准确性，内容的完整性。走得通：字幕准确，内容完整；走不通的信号：说与字幕对不上，中文英文对不上，内容不完整。
  - 听他说 60 小时/周、每天 10 小时、一周 6 天的节奏，和有了孩子之后怎么调的
  - 🔍 Carmack 说 12 小时之后脑子就"变成糊状"，他知道自己的上限在哪
  - hard work 是需要的，如果要达成具体目的。为了目标多工作两小时只会收获更多， 临界点。lex 则强调 hard work 则使得未来几周 peak hours 的表现更好。这里只是纯粹讨论是否成为大师，这个观点成立。
  - 他的努力工作源自有多种选择，并把时间用在最合适的地方上。
  - 🌵 点评：Carmack 这个虽然对于 hard work 的认同（包含 lex 的补充）、了解自己一日 12 小时会把脑子干糊就固定 10 小时 hard work 的观点也算可以听听，但 work life balance 这块的理解比较有意思：因为某块（做研究 / 整理 / 设计 / 编写代码）更重要了就把时间切过去，或者让自己可以把目光转向其他事情，这样在他的实践下就几乎没有 burnout 疲倦的时刻（我不想关心了，我不想再做这个了）。只要快乐最大化，就算是 wlb 了。
- [x] 🌟🌟(🌟) 读 antirez 的个人主页 invece.org 和 antirez.com 的博客 — 注意他写的几句话："Life is too short to work like crazy for most of its part"、"Programming is art, if done in certain ways"
  - 🔍 Redis 维护了 11 年之后他选择离开，写了科幻小说 WOHPE，4 年后回归。他妻子说 Redis 头几年主要是在马桶上用 MacBook Air 11 写的，他在主页上承认这是事实
  - [The end of the Redis adventure](http://antirez.com/news/133) — 为什么离开
  - [From where I left](http://antirez.com/news/144) — 为什么回来
  - [博客首页](http://invece.org/)
  - 🌵 点评：Antirez 的 2020 离别 redis，交由负责多且愿意去理解 redis 愿景的两个哥们。项目在 web 2.0 的某个 problem-solve 循环的一节中诞生，在作者 11 年推进项目过程中，由于项目演进特性，自我表达的减少而离开，4 年后则由于融入技术世界的紧迫感而回归。总的来说，是一个因兴趣与创作代码艺术而投入 redis 开发的人，过程中 burnout 后退出，后因始终喜欢技术而回归。

## Phase 1 — 拆解三种原型 (~30min)

三个人，三种做法。

- [x] Carmack（强度型）— 信的是"工作更多就能完成更多"，把工作时间往深夜挪来避开打扰。他的 .plan 文件（公开日志）全是任务记录，看不到任何生活内容。休息这件事对他来说是私事
- [x] antirez（艺术家型）— 自称 "far from being a workaholic"，写出了 Redis。离开 Redis 后写科幻、拍 YouTube、研究复古计算。他按有趣/无聊来分，不管一件事算工作还是娱乐
- [x] 🌟🌟🌟🌟 ThePrimeagen（输出型）— 前 Netflix 工程师，全职做技术内容。GitHub 上有个叫 "anime" 的 repo 放二次元壁纸。Twitch 直播时边写代码边聊动漫
  - 💡 他的做法：消费（看番）→ 输出（直播讨论）→ 变现（观众），娱乐和工作在他那里是一条流水线
  - 验证什么：看看他的视频风格（在技术背景下）；走得通：风格有意思；走不通的信号：无感。确实无感

## Phase 2 — 找到跟你有关的部分 (~15min)

不用全盘接受哪种模式，找几个碎片就行。

- [x] 🌟🌟🌟 写下你对三个人的第一反应 — Carmack 的强度你受得了吗？antirez 那种"想做什么做什么"你敢吗？ThePrimeagen 把兴趣变成工作你愿意吗？每个一句话

    Carmack 那个受的了但总觉得产出不及 Carmack。antirez 和 Carmack 在完成目的上我认为没差别，单纯是 antirez 担子感重，没意识到目光可以转向其他事情。ThePrimeagen 无感，他的行为我没深入了解，单纯是看他的 reaction 没什么有趣的地方。

- [x] 画一条线，一端写"严格分离"，另一端写"完全融合" — 把三个人和你自己标上去

- [x] 🌟🌟🌟 你目前最大的卡点是什么 — "想工作但总在刷手机"？"看完番有负罪感"？"不知道什么时候该停"？写下来

    “想工作但总是在刷手机”，不会。“看完番玩游戏有负罪感”，看完玩完倒是一般都是享受，就是看的过程和玩的过程有时有，会想工作的事。“不知道什么时候该停”，我基本都是看完和玩完再停的，不是一天就是三天，中间想工作也基本做不了。说实话阅读这些大牛的一些看法，是有所启发，只不过除了 carmack 神秘的周日外，其他对于如何安排娱乐没什么见解，虽然 wlb 的不同看法让我稍微不太在意什么是 work 什么是 life 了。

## Phase 3 — 一周实验 (~5min/天 × 7天)

选一个小改变试一周。

- [ ] 三选一，执行 7 天：
  - 🌟🌟🌟🌟 A) Carmack 式：每天精力最好的 3 小时，手机静音，只做一件事。不如晚 6:00 ~ 10:00（开始时间也不会很准时，当作 3 小时）全程无干扰做事。
  - B) antirez 式：每天花 30 分钟做一件跟产出无关的事（看番、画画、瞎写），不找理由
  - C) ThePrimeagen 式：这周看的番/电影/文章里挑一个，写 3 句感想发出去，把消费变成输出
- [ ] 第 7 天回顾 — 更舒服了还是更别扭了？别扭就换一个再试一周

## Phase 4 — 品味校准 (~5min)

- [x] "工作与生活平衡"这个说法，对你有用吗？上面三个人里谁在追求"平衡"？

    wlb 是我之前没怎么考虑，花了两天时间搜集（至少我认为的）大牛们的工作哲学后——从博客、博客中——就之后再也不怎么考虑的一个议题了。如果处在一个选择比较多的人生阶段，将时间投入到最合适的地方，比如当前研究、整理（含日常）、交际、设计、构建项目等某一块重要性突出了，这使得满足感最大化。那尝试说明 XX 归属于工作，YY 归属于生活，某项组合投入 ZZ 时间则心态平衡，尝试这种「事物的二分分类」和「静态组合」可能就没什么必要了。

- [x] 你观察到的最意外的一点是什么？比如 antirez 自称不是工作狂但写出了用户量最大的内存数据库之一

    说实话挺能理解的。

- [x] 一句话结论 — 有人问你"技术大牛怎么安排娱乐"，你怎么答？三个月后回来看看答案变没变

    允许目光转向其他事情。投入进自己关注的，别管 wlb 了。
